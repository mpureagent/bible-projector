## 任务（每任务一个 commit：T4-font / T4-layout / T4-style / T4-keys）

### 任务 1：字体子集化（T4-font）
- 从 `generated/bible.json` 全量经文提取字符集（确定性、可审计），用 fontTools 对 Noto Serif CJK SC 做子集，输出 woff2（目标 ≤5MB，§2.4 安装包体积约束），同时保留回退链声明（§7.3）
- 测试/证据：子集字符覆盖率 100%（对照提取集逐字符断言）、产物字节数实测写入报告（超标须如实报告不得硬凑）

### 任务 2：投影排版引擎（T4-layout）
- 段落合并模式（整章连续排版）/ 单节模式（一次一节超大字），§2.2
- 溢出分页：单章 ≤176 节全量渲染下按视口自动分页；↑/↓ 翻节、PgUp/PgDn 翻章时翻页跟随
- 字号上限 200px、边距 ≥8% 安全区（§11 风险行）；可隐藏节号、可隐藏书卷标题行（§2.2）
- 经文切换→投影更新 ≤100ms：实测数字（performance 用例 ×100 取中位数）写进测试日志
- 测试：两模式 DOM 断言、分页边界（176 节长章）、隐藏开关组合、性能中位数

### 任务 3：样式面板 + 主题（T4-style）
- 样式抽屉（§6.2 右抽屉，S 或齿轮唤出）：字体（内嵌宋体/系统宋体/楷体/黑体）、字号、字色、节号色、当前节高亮色、背景色/背景图（内置 3 张素雅纹理随包 + 自定义本地文件）、行距、字距、对齐、边距（§2.3 全项）
- 预设主题 3 套（墨金/米白/深蓝，§7.2）一键套用；所有设置实时广播投影窗 + 持久化 config.json
- 内置 3 张纹理：程序化生成（SVG 渐变/纹样），不许外链下载；单张 ≤200KB
- 使用项目内 ui-ux-pro-max / design-system skill 的 token 规范（§5.2 色值已在 themes.ts，扩展而非另起）
- 测试：样式 action→store→广播 payload 字段级断言、主题切换三套 token 全等、自定义背景图路径校验（拒绝网络 URL）、持久化重载

### 任务 4：快捷键全集 + 投屏控制（T4-keys）
