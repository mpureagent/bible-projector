## 任务（每任务一个 commit：T5-config / T5-build / T5-audit / T5-release）

### 任务 1：打包配置（T5-config）
- package.json `build` 字段落定：appId（com.shengyan.projector 或同类）、productName、`files` 白名单（dist/renderer + generated/bible.json + asar 资源，**排除** src/tests/docs/.qoder/.artifacts/node_modules devDeps 泄漏）、nsis（oneClick=false, perMachine=true, 允许改安装目录）、portable、zip 三 target
- 图标：用 PIL 或 node canvas 程序化生成一枚简素图标（十字/书本意象，OFL 色系），转 .ico 入 build/；生成脚本入 repo 可复现；生成失败则如实报告并沿用 electron-builder 默认图标（不得手找外链下载）
- `npm run build` 全流程串通：build-data → vite 双入口 → tsc 主进程（chrome108 target 不回归）

### 任务 2：出包 + 体积断言（T5-build）
- `npx electron-builder --win` 出 **Setup.exe（nsis）+ Portable.exe + win-x64.zip** 三产物到 dist/
- 断言 §2.4：Setup ≤120MB——**实测字节数写进输出报告**（三产物各 stat 一次），超标不得硬压，如实报告数字
- 产物完整性抽检：zip 解包后 win-unpacked 含 bible-serif-sc.woff2、bible.json、纹理 SVG、双入口 html（列清单）；asar 内无 src/tests/docs 泄漏（`npx asar list` grep 断言）
- 若 wine/NSIS 链接环节真实失败：如实记录失败点 + 完整错误，回退方案=先交 zip+portable 两产物并报告（Setup 缺口转 PM 处置），不得伪造成功

### 任务 3：离线与安全审计（T5-audit）
- CSP 生效断言：dist 产物 index html 含票面 §9 CSP 头；渲染进程对 `http:`/`https:` 外链引用 grep=0（fonts/textures/api 全本地）
- 运行期网络=0 实测：Xvfb 起打包后的 **win-unpacked 版在 Linux 不可跑**——改为：a) 打包前用 Linux electron 跑 dist 版，主进程挂 `session.webRequest.onBeforeRequest` 计数器，走一遍 E2E 关键路径（启动/选经/切主题/黑场），外部请求计数断言=0（file:// 与 devtools 除外），日志数字进报告；b) 如实声明此为 Linux 代理性验证，真机 Windows 断网复验归用户 M4 验收步骤
- 冷启动与内存参考值：同法计时"主窗可交互"×3 次取中位数（Linux 参考值，注明非 Win7 HDD 承诺值）；RSS 峰值采样 ≤300MB 参考
- vitest 全量仍绿（只增不减，基线 194；新增审计脚本测试则计入）
