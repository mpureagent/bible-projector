# T6 任务单：真机验收返工（投屏模型重构 + 多选 + 控制窗重排 + 搜索修复）

- 提出人：Hermes（PM）
- 执行人：Qoder（GLM-5.3 QwenCloud 通道，high 档）
- 日期：2026-10-17
- 背景：用户 Windows 真机验收发现 5 项问题（编号 1-5），其中问题 4（单屏打开即被投影窗全屏吞屏、无法退出）为 P0 交互缺陷，根因已定位：`src/main/windows.ts:35 fullscreen: !smoke` ——投影窗无条件全屏创建，且不接收控制窗键盘处理器（Esc 失效）。
- 版本目标：v0.9.1，重出三产物传 Release v0.9.1-m5

## 需求清单（用户原话归纳）
1. 节列表支持**多选**（投屏常投多个小节）
2. 控制窗重新设计：左侧搜索，右侧经文；**底部状态条多余，删除**
3. **取消"选中即投屏"**：加投屏按钮，投屏/取消投屏由按钮触发；选中默认本地阅读模式（不上投影窗）
4. 单屏环境打开软件投影窗全屏占满屏幕、无按钮、退不出（P0）
5. 搜索下拉与输入框禁横向滚动；结果每卷一行、默认展示全名（放不下换行，不截断）

## 任务（每任务单独 commit：T6-project / T6-multiselect / T6-layout / T6-search / T6-release）

### 任务 1：投屏状态模型（P0，最先做）（T6-project）
- AppState 增 `projecting: boolean`（默认 **false**）；投影窗**默认隐藏**（不创建可见窗，或创建后置 hidden——实现自定，验收看行为）
- 控制窗顶栏增**「投屏 / 取消投屏」大按钮**（≥40px 触区，与黑场/锁屏并排），切换 projecting；快捷键 `P` 同义（更新 §6.3 键位表：新键 P；Esc 语义扩展：投影窗内 Esc 等效取消投屏，确保永远可退出）
- **单屏保护**：目标显示器为系统唯一 display 时——投影窗以普通窗口（1280×720、有标题"投影预览"、可关闭）显示，**禁止 fullscreen**；双屏时投屏 = 全屏铺满第二屏。`windows.ts:35` 的无条件 fullscreen 必须废除
- 本地阅读模式（projecting=false）：选经/多选只更新控制窗预览，投影窗不接收更新；投屏瞬间把当前选区推上投影窗
- 测试：projecting 状态迁移、单屏不全屏（mock 唯一 display）、投屏/取消的广播时序（未投屏时选经不得产生投影广播）、P/Esc 键位

### 任务 2：节多选（T6-multiselect）
- 节列表：**点击=勾选/取消勾选**（支持非连续，如 1、3、7），Shift+点击=连选范围，提供"清空选择"入口
- Selection 数据结构：`verses:{from,to}` → **有序节号集合**（如 [1,3,5,6,7]）。适配五处：types/IPC 契约、store（广播/持久化）、历史（条目摘要"创1:1,3,5-7"式压缩显示）、投影渲染（按集合渲染所选节+分页）、控制窗预览
- 跨章选择：允许（换章后前一章已选保留；投影按 书:章:节 列表显示）；历史条目含跨章摘要
- 测试：集合增删/非连续/Shift 范围/清空/跨章保留、历史摘要格式化、投影按集合渲染断言；既有 from-to 语义用例迁移改写（数量不减）

### 任务 3：控制窗重排（T6-layout）
- 布局：左栏=搜索框+旧/新/历史 Tab+书卷网格（320px 不变）；右主区=章列表→节列表（带勾选态视觉：勾选框/高亮）+所选经文预览（与投影同排缩小版）；**删除底部 dl/dt 状态条**，selection 关键信息并入预览区标题行（如"创世记 1 章 · 已选 3 节"）
- §6.1 原则更新为：**三次点击选中，一键投屏**；文档同步由任务 5 处理
- 测试：DOM 结构断言更新（状态条不存在、预览标题含选中计数）、点击路径 E2E（书→章→勾节→投屏按钮）截图

### 任务 4：搜索下拉修复（T6-search）
- 结果面板宽度=左栏，**overflow-x: hidden**；每卷一行、主文案为**全名**（哥林多后书等长名行内自动换行，禁止 ellipsis 截断全名）；匹配来源徽标（全名/简称/拼音）保留但不得挤压主文案；输入框文本完整显示不裁剪（input 超长时右对齐可见尾串）
- 测试：长卷名（哥林多后书/启示录）渲染断言、无横向滚动样式断言（computed style overflow-x hidden）
