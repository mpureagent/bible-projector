## 任务（按序执行）

### T7-projection：投屏模型补全（R1 剩余部分）
- 投影窗**默认不创建**：启动=未投屏无任何投影窗；「投屏」按钮创建并显示，「取消投屏」销毁
- 自动上屏：有外接屏（screen.getAllDisplays() >1）→ 投影窗全屏到第二屏；无 → 本机浮动窗 1280×720 非全屏，标题"投影预览"，顶栏一行提示"电视请用 Win+P 扩展模式"
- 主屏永不劫持：投屏后工作窗可最小化，投影窗独立存活；焦点全程不强制
- 删除黑场（blank）与锁屏（lock）：keymap/store/render/UI/IPC 全链路移除，相关测试改写为"功能不存在"断言；F/Esc=取消投屏；↑↓ 高亮、PgUp/PgDn 滚动保留
- 热插拔兜底：display-removed 时若投影窗在该屏→自动降级为本机浮动窗不崩
- 测试：默认无窗/按钮创建销毁/单屏浮动不全屏/多屏自动全屏（mock screen）/焦点不抢占断言

### T7-cascade：四列级联选经（R2）
- 弹窗：书|章|起始节|结束节 四列一体，点列刷新右侧列；起始>结束自动交换或钳制（自定并测试）；选完自动关窗出预览
- 浮层定位：覆盖在搜索+预览区之上，不占固定布局；点遮罩/✕/选完 三途径关闭
- 「当前选区」标签在操作条，点击重新唤起弹窗回填修改；历史条目点击=直接回填选区
- 数据结构维持 (sn, chapter, from, to)（v0.9.0 from-to 复用）；**不支持跨章**；删除 Shift 连选旧交互
- 历史：范围式"创世记 1:1-3 · 10:15"，容量 50 去重合并逻辑沿用
- 测试：级联列刷新/起止钳制/回填修改/不跨章/历史摘要格式

### T7-layout：控制窗重排（R3+R6）
- 左栏：搜索框（顶）→ Tab「旧约|新约|历史」→ 书卷列表**每卷一行全名**（简称次要显示），overflow-x:hidden 无横滚；搜索下拉同宽、全名不截断可换行、前缀高亮保留
- 右栏操作条（预览顶上，左→右）：**[投屏/取消投屏]主按钮** → **当前选区标签**（未选灰）→ **复制经文钮**（小）→ **A−/A+** → **8 主题色板选择器** → **⚙抽屉入口**
- 删除底部状态条 DOM；预览区文本**可选中可复制**（user-select 不禁）
- 预览与投影**同源渲染**（同一排版核，字号缩放）：主题/字体/行距/节号显隐全跟随样式状态——修复验收问题6"主题不生效"
- 测试：布局 DOM 断言、状态条不存在、复制可用性（selection API 冒烟）、主题切换预览 computed style 全等 token（问题6 回归用例）

### T7-flow：自然段落流 + 纵向滚动（R2/R4 排版侧）
- 渲染：经文按**自然段连续流**（不再一节一行），节号上标 ¹²³ 嵌句首，默认显示、样式开关；当前节高亮=段内句子级点亮；废除单节模式与 computePages 分页引擎（删除或退役为纵向滚动，孤页语义随之消失）
- 投影交互：纵向瀑布；**按住拖动=滚动（跟手+惯性缓停）**；单击不翻页；PgUp/PgDn=滚动一屏；↑↓高亮移动且**高亮移出视口自动滚动跟随**
- 底部细滚动进度条：无箭头无页数；淡显 30% 透明，静止 3s 全隐，滚动/翻页重现
- 测试：段落流 DOM（上标计数=节数、无逐行列表结构）、滚动跟随（scroll 位置断言）、进度条显隐状态机、拖动惯性参数边界
