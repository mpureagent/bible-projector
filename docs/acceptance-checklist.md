# 验收手册（Windows 真机）· 圣言投屏 v0.9.0-m4

> 交付验收专用。建议顺序：先家里 Win10/11 跑通，再到教会 Win7 终验。
> 下载：https://github.com/mpureagent/bible-projector/releases/tag/v0.9.0-m4
> 产物：Setup 66.8MB（安装版，首选）/ Portable（免安装备用）/ zip（解包版）

## 准备

- 机器：Win7 SP1 64位 或 Win10 64位；**管理员账号**（教会电脑已确认）；接电视的第二个显示器/投影
- 下载 Setup exe

## 第 1 关：安装与首启

- [ ] SmartScreen 弹"Windows 已保护你的电脑"→「更多信息」→「仍要运行」属**预期行为**（未代码签名，非病毒）
- [ ] Setup 安装：可选目录（默认 `C:\Program Files\圣言投屏`）→ 桌面出快捷方式
- [ ] 冷启动 ≤3s：象牙白控制窗 + 深墨底投影窗 两窗同现

## 第 2 关：讲道主流程（核心体验）

- [ ] **三次点击出经文**：点"创"→点"1"→点"1"→电视即显"起初，神创造天地。"金字，上屏无感延迟（承诺 ≤100ms）
- [ ] 拼音搜索（下拉即时过滤）：
  - `sp` → 诗篇；`mkfy` → 马可福音；`l` → 出现林前
  - `爱世人` → **无任何结果**（仅搜卷名，设计如此非 bug）
- [ ] 快捷键全集：`↑↓` 翻节｜`PgUp/PgDn` 翻章｜`B` 黑场/恢复｜`L` 锁屏（锁定后其他键全失效，再按 L 解锁）｜`F` 投影全屏｜`+−` 字号｜`S` 样式抽屉｜`Esc` 退黑场/全屏
- [ ] 历史 Tab：近期选择都在，点一条一键回跳上屏

## 第 3 关：样式与距离

- [ ] `S` 开样式抽屉 → 三套主题（墨金/米白/深蓝）一键切换，投影窗实时跟变
- [ ] 试改：字色、背景色、行距、字号
- [ ] **人肉判定**：退到 3~5 米（会众席距离）看默认字号清不清晰、累不累眼；偏小按 `+`
- [ ] 括号旁注（如"（原文是弟兄）"）原样显示——数据核查后定的 A 方案，现场观察是否碍眼
- [ ] 退出重开：主题/字号/历史仍在（持久化）

## 第 4 关：离线与安全

- [ ] **拔网线/断 WiFi** 再走一遍第 2 关 → 全部功能照常 = 运行期零网络成立
- [ ] 较真可看任务管理器：程序无网络活动

## 第 5 关：事故演练（接电视必做）

- [ ] 投影中有经文时**拔电视 HDMI**：投影窗回退主屏继续显示，控制窗顶部亮「⚠ 投影回退主屏」，不黑屏不闪退
- [ ] 插回：自动迁回电视屏；若换了输入源（新设备），顶栏显示器下拉一键改选即恢复

## 收尾

- [ ] 卸载：安装目录与快捷方式清除；`%APPDATA%\圣言投屏`（配置/历史）**保留属设计**，要彻底清除手动删该目录

## 判定与反馈

- **通过**：五关全绿 → 交付教会日常使用
- **异常回传三要素**：① 哪一关哪一步 ② 现象/截图 ③ 机器（Win10 家里 / Win7 教会）——定位后开修复票
