## 一、家里段（Win10/11 + 外接电视，可全流程验证）

### 前置
- [ ] 管理员账号；笔记本/台式机接**第二块屏**（电视或显示器）；两屏建议 **Win+P → 扩展**
- [ ] 装 `Setup-0.9.2.exe`（见教会段 SmartScreen 图解，家里首装同样适用）
- [ ] 覆盖升级注意：v0.9.0 的旧配置/历史会**自动迁移**（见「第 6 关」）

### 第 1 关：安装与首启（无劫持）
- [ ] Setup 安装向导可选目录，**默认钉在** `C:\Program Files\圣言投屏`（不再被旧卸载键带到别处）；桌面出快捷方式
- [ ] 冷启动：仅出现**象牙白控制窗**；**此时不含任何投影窗**（未投屏=无画面，主屏不被劫持）

### 第 2 关：级联选经（新交互）
- [ ] 左栏点任意书卷 → 浮出**四列弹窗**（书 | 章 | 起始节 | 结束节）
- [ ] 点「章」列→右列刷新；点起始节→结束节列出现；点结束节→**自动关窗**、右侧预览出经文
- [ ] 起始>结束 时结束自动抬到起始（不报错）
- [ ] 操作条「当前选区」标签显示 `约翰福音 3:16-17` 式；再点它→弹窗回填当前选择，可改选
- [ ] 点弹窗遮罩 / 点 `×` → 关闭；搜索框输入 `sp`→诗篇、`mkfy`→马可福音、`爱世人`→**无结果**（设计如此）
- [ ] 「复制经文」按钮：复制后粘贴到记事本，内容=参考行+逐节经文

### 第 3 关：投屏与滚动（核心体验）
- [ ] 点操作条**「投屏」**→ 有外接屏时投影窗**自动全屏到第二屏**；主屏控制窗可最小化、可继续操作，**焦点不被抢**
- [ ] 投影窗内经文按**自然段落连续流**排版（不是一节一行），节号上标嵌句首
- [ ] **拖动投影窗=纵向滚动**（跟手、松手惯性缓停）；**单击不翻页**
- [ ] 控制窗 `PgUp/PgDn` = 投影滚动一屏；`↑↓` 移动当前节高亮，高亮**出屏自动滚动跟随**
- [ ] 底部细进度条：滚动时淡显，**静止约 3 秒后全隐**，再滚动重现
- [ ] 点**「取消投屏」**（或控制窗/投影窗按 `F`/`Esc`）→ 投影窗销毁，电视无画面
- [ ] 单屏测试（拔掉外接屏）：投屏=本机浮动窗「投影预览」1280×720，顶栏提示「电视请用 Win+P 扩展模式」，**不吞主屏**
- [ ] 热插拔：投屏中**拔 HDMI** → 投影自动退回本机浮动窗不崩；插回→自动迁回第二屏

### 第 4 关：样式（8 套主题）
- [ ] 操作条主题色板 = **8 个色块**；点任一色块→预览与投影**同时换主题**（所见即所得）
- [ ] `⚙` 开样式抽屉：8 主题缩略图｜字体（宋体/黑体/楷体/系统默认）｜字号滑块+A±｜行距/字距｜对齐左/居中｜边距｜节号显隐
- [ ] 背景**三选一**：内置纹理(3) / 自定义图片(本地路径) / 纯色（取色器）——选纯色会清空纹理（互斥）
- [ ] 「重置为当前主题」清空全部自定义，回归主题本色
- [ ] 点 `×` 或抽屉外遮罩 → 关闭抽屉
- [ ] **看图挑主题**：对照 `theme-gallery-0.9.2.zip`，选出家里最顺眼的前 3 名带去教会
- [ ] 退出重开：主题/字号/背景/历史仍在（持久化）

### 第 5 关：离线与安全
- [ ] **拔网线/断 WiFi** 再走第 2-4 关 → 全部功能照常（运行期零网络）
- [ ] 播放/切主题时亦无任何联网请求（较真看任务管理器）

### 第 6 关：旧数据迁移（覆盖升级）
- [ ] 若本机装过 v0.9.0：首启后打开 `%APPDATA%`，应见新目录 **`圣言投屏`**（含 config.json/history.json/Local Storage），
      旧目录 **`bible-projector`** 已改名为 `bible-projector.migrated`；历史记录/主题在软件里仍在

## 二、教会段（Win7 SP1 64位 + 真电视）

### ⚠️ 最高风险项置顶：Win7 首装（本手册第一件事）
> Electron 22 / Chromium 108 是 Win7 可用的最后基线，但**从未在 Win7 真机实测过**。
> 家里 Win10/11 通过 ≠ Win7 通过。教会终验的第一件事就是装它、跑通第 2 关。

- [ ] Win7 SP1 x64 安装 Setup（若 Setup 装不上，**退化用 Portable 免安装版**先跑通）
- [ ] 若启动即失败（缺 VC 运行库/显卡驱动过老等）→ **当场记录**：哪一步、报错截图、机器型号 → 回传开修复票
- [ ] Win7 能跑通后，再按下面的电视流程验收

### 第 1 关：SmartScreen 安装图解（未签名，必看）
1. 双击 `Setup-0.9.2.exe` → 出现「Windows 已保护你的电脑」蓝色警告（**未代码签名，属预期，非病毒**）
2. 点「**更多信息**」 → 出现「**仍要运行**」按钮 → 点它 → 进入安装向导
3. 安装向导可选目录（默认 `C:\Program Files\圣言投屏`）→ 完成，桌面出快捷方式
- 技巧（可选）：右键 exe → 属性 → 常规页底部勾「**解除锁定**」→ 确定，之后再运行不再拦
- [ ] 三步图解照做安装成功

### 第 2 关：投屏主流程（电视侧）
- [ ] **前提**：电视须 **Win+P → 扩展模式**（镜像模式下"主屏自由 + 电视净画面"物理不可兼得）
- [ ] `sp`→诗篇→23 章→1-3 节：电视上出现连续段落经文（节号上标）
- [ ] 拖动/`PgUp/PgDn` 滚动，会众席看着是否跟得上；`↑↓` 高亮跟读
- [ ] `F`/`Esc`/「取消投屏」退出；投屏中拔 HDMI 不崩

### 第 3 关：距离可读性（人肉判定）
- [ ] 退到会众席实际距离（约 3~8 米），用家里挑出的前 3 主题逐一试
- [ ] 判断：字号够不够大（`+` 可调，上限 200px）、底色与字色冲不冲、亮环境反光如何
- [ ] 括号旁注（如「（或译：…）」）原样显示，现场观察是否碍眼

### 第 4 关：断网复跑
- [ ] 拔网线后重建一次投屏流程 → 照常；确认教堂现场无网络也能用

## 已知边界（如实声明）

- **未代码签名**：SmartScreen 警告不可避免（不买证书/不自签；未来公开发布再议）
- **Win7 真机从未实测**：唯一未验证风险点；教会首装即验，失败当场记录回传
- **楷体**：本机无楷体源文件 → **不内嵌**，仅走系统回退链 `'楷体','KaiTi',serif`（Windows 自带楷体，离线成立）；黑体/宋体已子集化随包
- 性能口径：冷启动/内存数字为 Linux 开发机参考值，非 Win7 HDD 承诺值，以真机实测为准
- 竖排、跨章选择、网络背景图：**不支持**（设计如此）
